# CD Projekt — Cash Flow First Analysis

Interaktywny microsite analityczny poświęcony Grupie CD PROJEKT, przygotowany w podejściu **cash-flow-first**.

Analiza koncentruje się na płynności, jakości przepływów operacyjnych, bezpieczeństwie bilansu, nakładach na rozwój gier, pipeline oraz ryzyku wykonania przyszłych premier.

## Główna teza

CD Projekt to finansowo bezpiecznie ustawiona spółka wysokiego ryzyka projektowego.

Gotówka daje czas. Bilans daje bezpieczeństwo. Pipeline daje potencjał wzrostu. Ryzyko wykonania zdecyduje o wartości dla akcjonariusza.

## Zakres analizy

Projekt obejmuje:

- analizę cash engine i CFO,
- analizę płynności i struktury bilansu,
- ocenę jakości zysku względem gotówki,
- analizę development burn,
- ocenę pipeline jako źródła przyszłej wartości,
- identyfikację red flags,
- appendix ze wskaźnikami finansowymi,
- skrócony fact sheet inwestorski.
